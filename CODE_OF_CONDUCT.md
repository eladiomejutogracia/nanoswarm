# Code of conduct

NanoSwarm follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep criticism about the work, not the person.
Harassment, insults and personal attacks are not welcome in issues, pull requests, discussions,
or anywhere else the project lives.

If something happens, tell the maintainer privately, through the contact on
[their GitHub profile](https://github.com/eladiomejutogracia). Reports are kept confidential.
The maintainer may remove content, or block people, who break these rules.

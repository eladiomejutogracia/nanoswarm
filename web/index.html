c
Optional color, 0 → 1 along the colors. Without it: bottom → top.
other names
Helpers you can use in later lines.
noise(x, y, z)
Smooth randomness, −1 → 1.
spectrum(k)
The music: loudness at frequency k, 0 = bass → 1 = treble.
